# Chaika Team — Frontend

React + TypeScript + Mantine. Сборка через Vite. Интерфейс аналитики ресторанной сети: обзор, продажи, закупочные цены, накладные, перемещения, списания, номенклатура, техкарты, остатки, сотрудники, события заказов и чат помощника.

Бэкенд находится в отдельном репозитории `TeamChaika/team_back`. Браузер работает с API FastAPI по относительному пути `/api`; реквизиты iiko и PostgreSQL во фронтенде не используются.

## Установка и сборка

Нужны Node.js 22 LTS и npm. Из корня репозитория:

```sh
npm ci
npm run build
```

Готовый сайт находится в `dist/`. TypeScript проверяется при сборке.

## CI/CD

`.github/workflows/ci.yml` при push в `chaikaiiko`, при pull request и вручную выполняет `npm ci` и `npm run build`. Готовый `dist/` сохраняется артефактом с идентификатором коммита. Сборка не требует рабочих секретов.

Для автоматического развёртывания можно добавить отдельное CD-задание, использующее этот артефакт, после выбора сервера и настройки доступа. Сейчас workflow проверяет и собирает приложение, но не публикует его на сервер.

## Совместный запуск

Разместите папки рядом:

```text
team_back/
team_front/
```

В локальном `.env` бэкенда задайте:

```dotenv
CHAIKA_WEB_FRONTEND_DIR=../team_front/dist
CHAIKA_WEB_ORIGIN=http://127.0.0.1:8013
CHAIKA_WEB_SECURE_COOKIE=false
```

После сборки фронтенда запустите `app.portal:app` из папки backend на порту 8013. Сайт и API будут доступны на http://127.0.0.1:8013/.

## Разработка с Vite

```sh
npm run dev -- --port 5173 --strictPort
```

Vite проксирует `/api` на `http://127.0.0.1:8013`. Для этого режима установите в backend `CHAIKA_WEB_ORIGIN=http://127.0.0.1:5173` и перезапустите процесс портала. Открывайте сайт по этому же адресу: проверка Origin защищает вход и выход.

## Публикация

Раздавайте `dist/` вместе с FastAPI либо через HTTPS reverse proxy с маршрутом `/api` к `app.portal`. Для клиентских маршрутов нужен fallback на `index.html` — он уже предусмотрен в портале. В backend настройте публичный `CHAIKA_WEB_ORIGIN` и `CHAIKA_WEB_SECURE_COOKIE=true`. `npm run preview` предназначен для локальной проверки сборки.

Репозиторий содержит исходники и lock-файл. `node_modules`, `dist`, локальные настройки, рабочие учётные данные и выгрузки базы в Git не добавляются.
